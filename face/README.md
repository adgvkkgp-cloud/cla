# Таксономия лица

Справочник лица: анатомия и морфология, мимика и микровыражения, эстетика
и каноны, фенотипические черты, типажи и арт-теги в нотации Danbooru/Gelbooru.

**41 часть · 156 разделов · 2868 позиций**

## Как посмотреть

`TAXONOMY_FACE.html` — самодостаточный одностраничник, всё внутри одного файла.
Открывается по локальному HTTP (не по `file://` — браузер заблокирует загрузку
скриптов):

```bash
cd face
python3 -m http.server 8080
# http://127.0.0.1:8080/TAXONOMY_FACE.html
```

Есть поиск по названию, описанию и тегу, лента частей, раскрытие разделов
и переключатель тегов. Клик по тегу ищет по нему.

## Сборка

```bash
npm install
npm run build     # проверка → vite → TAXONOMY_FACE.html
npm run check     # только проверка данных
npm run dev       # рабочий сервер
```

`npm run build` сначала прогоняет `tools/check.cjs` и не собирает ничего,
если данные не прошли проверку.

## Проверка целостности

`tools/check.cjs` роняет сборку, если корпус разошёлся сам с собой:
повторяющиеся названия позиций, повторяющиеся id разделов и частей, пустые
поля, дыры в нумерации внутри раздела, цвет раздела вне палитры `App.tsx`,
расхождение `TOTAL_COUNT` с числом позиций.

Главная из проверок — повтор названия. Именно так корпус и портился: части
дописывались поверх уже существующих, а не в них, и одна и та же черта попадала
в него по второму и третьему разу, каждый раз с чуть другим описанием. Вручную
это не ловится: к тому моменту, как повторов стало 152, разглядеть их в файле
на 4700 строк было уже нельзя.

Черта, которую нужно назвать дважды в разных рамках, называется по-разному:
«Высокие скулы» (анатомия), «Высокие скулы как канон красоты», «Высокие скулы
(южноазиатский тип)».

## Регистр описаний

Описание называет признак, по которому черту опознают глазом, и меру, если она
есть: «Лицевой индекс > 90», «угол прикрепления > 30°», «Рассеяние Тиндаля,
малый меланин», «видно больше 3 мм десны над верхним рядом». Не «Малая длина»,
а «Малая длина спинки, переносица к кончику идёт круто».

Три раздела живут по своим правилам, и короткая строка там — не пробел:

- **booru-разделы и арт-теги** — английский тег с русской глоссой
  (`smile` → «Улыбка»). Глосса переводит, а не пересказывает;
- **`facs-aus`** — описание называет мышцу (`Zygomaticus minor`), что для
  системы кодирования лицевых движений и есть ответ;
- **разделы комбинаций** (`combo-eye-brow` и подобные) — название задаёт
  сочетание черт, описание даёт его прочтение. В этом их смысл.

## Устройство

| Файл | Что это |
| --- | --- |
| `TAXONOMY_FACE.html` | Собранный одностраничник — всё в одном файле |
| `src/data.ts` | Корпус: части → разделы → позиции |
| `src/App.tsx` | Интерфейс: шапка, лента частей, поиск, раскрытие разделов |
| `tools/check.cjs` | Проверка целостности; роняет сборку |
| `tools/dedupe.cjs` | Разовое слияние повторов (оставлен как запись правки) |
| `tools/rewrite.cjs` | Разовое переписывание описаний (оставлен как запись правки) |
| `tools/emit.cjs` | Кладёт сборку в `TAXONOMY_FACE.html` |

### Формат

```ts
type Entry = { id: number; name: string; desc: string; tags?: string[] };
type Section = { id: string; title: string; subtitle: string; color: string; entries: Entry[] };
type Part = { id: string; title: string; emoji: string; sections: Section[] };
```

`id` позиции — порядковый номер внутри раздела, 1..n без дыр. `color` — одно
из шестнадцати имён палитры Tailwind, которые умеет рисовать `App.tsx`.

## Что было починено

Приложение пришло отдельно и чинилось в три захода.

**Интерфейс.** 42 вкладки частей переносились по строкам: прилипшая шапка
вырастала до 1464 px при экране 844 px — 173 % экрана, — и нижние два десятка
вкладок нельзя было нажать ни при какой прокрутке. Лента теперь прокручивается
вбок одной строкой, шапка занимает 252 px. Подписи вкладок резались по 20 знаков
посреди слова («АНАТОМИЯ И МОРФОЛОГИ») — обрезка снята. «↓ все» разворачивало
все позиции разом (страница 285 000 px, раскрытие дольше секунды) — тело раздела
монтируется по попадании в поле зрения, строк в DOM после «↓ все» стало 30
вместо 3004.

**Повторы.** 143 названия встречались не по одному разу — 152 лишние копии,
5 % корпуса. У 115 из них описания расходились, причём поздняя копия обычно
была хуже ранней: «Лицевой индекс > 90» превращался в «Лицевой индекс высокий»,
число терялось. 136 копий слито в профильные разделы с лучшим из описаний
и объединением тегов, 16 получили уточнённые названия, потому что называли одну
черту в разных рамках.

**Описания.** 139 описаний пересказывали заголовок: «Кудрявые волосы» →
«Локоны», «Короткий нос» → «Малая длина», «Высокий хвост» → «Хвост на макушке».
141 описание переписано; осталось одно — «Цианоз», и это термин, а не пробел.
Медиана длины при этом почти не сдвинулась (26 → 27 знаков): переписанное —
5 % корпуса, а остальные описания хоть и коротки, но содержательны.
