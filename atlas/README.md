# Атлас человека — данные

`data.js` — обновлённый массив `window.__TAXONOMY__` для того же вьюера, что был
в исходном архиве (`Atlas.dc.html` + `support.js`). Формат не менялся:

```js
window.__TAXONOMY__ = [
  { id, title, subtitle, icon, color, level, entries:[{ id, title, description }] },
  …
];
```

Разделы по-прежнему раскладываются по доменам через поле `level`, поэтому
исходный вьюер подхватывает файл без правок: достаточно заменить `data.js`.

Учтите, что `Atlas.dc.html` тянет React с `unpkg.com` и без интернета
показывает пустую страницу. Поэтому в корне репозитория лежит
`ATLAS_MEGA.html` — тот же атлас одним автономным файлом: данные, стили и
код внутри, внешних запросов нет.

## Что изменилось

* Снят вырожденный генераторный балласт: 20 009 позиций в 14 разделах были
  перемножением синонимов («Любит: кошки» / «Обожает: кошки» / «Боготворит:
  кошки» с описанием «предпочтение»; «Soft boy» / «Soft-тип» / «Soft-вайб» /
  «Soft-флёр» с описанием «поп-архетип / вайб «Soft»»). Разделы перестроены и
  дают 759 позиций с реальным содержанием.
* 17 419 описаний-шаблонов заменены содержательными: теперь ни одно описание
  не повторяется в атласе более четырнадцати раз.
* Исправлена рассогласованность в комбинациях: «Рукопожатие — вихляющая»,
  «Силуэт — нежные», «Манера говорить — вкусный» больше не встречаются.
* Добавлены 32 новых раздела и 1 719 понятий, которых в атласе не было.
