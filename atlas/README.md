# Атлас человека — таксономия

Интерактивная карта знаний о человеке: от хромосом и гормонов до психики, общества,
культуры и тончайших черт личности.

**601 раздел · 47 853 позиции · 8 доменов**

## Как посмотреть

`Atlas.dc.html` — самодостаточный вьюер. Семь режимов просмотра:

| Режим | Что показывает |
| --- | --- |
| Карта | Граф-дерево с погружением по уровням |
| Список | Разделы с раскрытием, слева — рельс доменов и дисциплин |
| Таблица | Плоский перечень тем с сортировкой |
| Плитка | Карточки доменов со сводкой по дисциплинам |
| Колонки | Домен → дисциплина → раздел → тема в четыре столбца |
| Связи | Темы, соединённые общими словами и тегами |
| ♂♀ | Только темы с различением мужского и женского |

Поверх любого режима работают поиск и полоса фильтров — по домену,
дисциплине, разделу, ярлыку, наличию механизма и граней пола.

### Ярлыки

Поле `tag` проставляется при сборке правилами из `src/data/tags.ts`,
а не руками по позициям. Ярлык у позиции один, порядок применения:
перебор → правило раздела → правило заголовка.

| Ярлык | Позиций | Что помечает |
| --- | ---: | --- |
| `сочетание` | 17 519 | 15 разделов, собранных перебором: список объектов × отношение |
| `патология` | 1 658 | Расстройства, синдромы, симптомы, фобии, зависимости |
| `классификация` | 760 | Виды, типы, формы, основания деления |
| `направление` | 667 | Школы, течения, парадигмы, -измы |
| `именное` | 315 | Понятия и эффекты, названные по автору |
| `историческое` | 272 | Эпохи, исторические институты, история дисциплин |
| `латынь` | 72 | Латинские формулы права |
| `спорное` | 49 | Возражения, критика, несостоятельные теории |

Помечено 21 312 позиций из 47 853 (45 %). Непомеченная позиция — это
норма: ярлык ставится там, где сужает выдачу осмысленно.

Главное, ради чего это сделано, — ярлык `сочетание`. Почти 39 % корпуса
это разделы вида «Любовь к: лесу», «Равнодушие: толпа» — один список
объектов, умноженный на семь отношений. Теперь их можно убрать
из выдачи одним щелчком, не удаляя из данных.

### Механизм

Поле `detail` — абзац о том, как устроено то, что названо в позиции:
из чего складывается, почему держится, чем разрывается. Это не второе
описание и не пример, а разбор устройства; там, где утверждение спорно
или держится на слабых данных, это сказано прямо в абзаце.

Абзацы лежат в `src/data/details.ts` таблицами вида
`{ "id-раздела": { "заголовок позиции": "абзац" } }` и дописываются
к уже существующим позициям при сборке, по точному совпадению заголовка.
Промах — заголовок, которого нет, — роняет сборку, поэтому таблица
не может разойтись с корпусом незаметно.

Написано 2 624 абзаца в 63 разделах (5,5 % корпуса). Поле заполняется
не сплошь, а по разделам: там, где за позицией стоит механизм, который
стоит объяснить. Один и тот же заголовок, встречающийся в нескольких
разделах, разбирается один раз — в том разделе, которому он принадлежит
по существу. То же правило действует внутри раздела: там, где одно
и то же понятие внесено под двумя названиями (`Tu quoque` и `Тю квокве`,
`Композиция` и `Ошибка композиции`, `Островковая доля` и `Островковая кора`),
механизм написан один раз, а у синонима поля нет.

### Грани пола

Поля `male` и `female` — короткая справка о том, чем различаются
мужчины и женщины по этой позиции. Правило заполнения жёсткое
и записано в `src/data/facets.ts`:

- различие называется вместе с величиной — «выше на 10–15 см»,
  «вдвое чаще», «разрыв рекордов около 10 %». Направление без
  величины почти ничего не сообщает;
- где различия нет, где оно мало́ по сравнению с разбросом внутри
  пола или где оно оспаривается, поле остаётся пустым. Пустое поле —
  честный ответ, а не пробел; вьюер ставит на этой стороне «—»;
- позиции о самой изменчивости и о совпадении диапазонов полей
  не получают вовсе: они говорят не о различии, а о том, как его
  читать.

Сборка роняется дважды: при промахе по заголовку и при попытке
внести позицию с двумя пустыми сторонами.

Заполнено 506 позиций в 55 разделах (1,06 % корпуса).

Открывается
по локальному HTTP (не по `file://` — браузер блокирует загрузку скриптов):

```bash
cd atlas
python3 -m http.server 8080
# и открыть http://127.0.0.1:8080/Atlas.dc.html
```

Вьюеру нужны `support.js` и `data.js` рядом (`icon.svg` и `manifest.webmanifest` —
по желанию, для установки на телефон).

### С телефона

Тот же файл, тот же адрес. Достаточно поднять сервер на компьютере и открыть
адрес вида `http://<ip-компьютера>:8080/Atlas.dc.html` — или положить папку
на любой статический хостинг.

Что сделано под мобильный экран (ниже 820 px по ширине или ниже 520 px по высоте):

- шапка переносится в две строки, счётчики сжимаются до `601 · 47 853`,
  поле поиска занимает всю ширину и получает шрифт 16 px — иначе Safari
  сам увеличивает страницу при фокусе;
- боковая панель превращается в нижнюю шторку: появляется только при выборе
  узла, имеет полоску-ручку и крестик, не скроллит страницу под собой;
- кнопки карты уходят вправо вверх и вырастают до 42 px, легенда доменов
  становится прокручиваемой строкой внизу, подсказка меняет текст на тач;
- жесты: одно касание — раскрыть, двойное — погрузиться, щипок двумя
  пальцами — зум, перетаскивание — панорама; область попадания по узлу
  увеличена с 16 до 26 px;
- граф на узком экране считается по более плотным кольцам и с короткими
  подписями, иначе после вписывания текст нечитаем;
- ландшафт телефона разбирается отдельно: панель сужается до 300 px,
  шапка и кнопки ужимаются, легенда и подсказка убираются;
- есть манифест и иконка — страницу можно добавить на домашний экран,
  она откроется без адресной строки.

Настольная раскладка не изменилась ни на пиксель: все мобильные правила лежат
внутри медиазапросов, а логика ветвится по ширине окна и типу указателя.

### Формат

```ts
interface Section { id, title, subtitle, icon, color, level, entries: Entry[] }
interface Entry   { id, title, description, detail?, male?, female?, tag? }
```

Поле `level` — не украшение: по нему вьюер раскладывает разделы по восьми доменам
и по подгруппам внутри них (`_domainOf` в `Atlas.dc.html`). Новый раздел с незнакомой
строкой `level` уедет в домен «Психика и личность» по умолчанию.

## Пересборка данных

```bash
cd atlas
npm install          # esbuild приходит вместе с vite
npm run build:data   # то же самое: node tools/build-data.cjs
```

Скрипт падает с ненулевым кодом, если найдёт разрыв в нумерации, пустое поле,
повтор `id` раздела или повтор заголовка внутри одного раздела.

## Правила пополнения

1. **Сначала ищем существующий раздел.** Новый раздел заводится, только если позиции
   действительно некуда положить.
2. Заголовок уникален внутри своего раздела. Одно и то же понятие может встречаться
   в разных разделах под уточняющим заголовком — например, «Ирония (фигура речи)»
   рядом с «Ирония» в разделе про юмор.
3. Описание — одно предложение, которое объясняет суть, а не пересказывает заголовок.
4. Новый раздел получает `level` из уже существующего набора строк, иначе он выпадет
   из своего домена.
