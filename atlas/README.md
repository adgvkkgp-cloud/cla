# Атлас человека

`ATLAS_MEGA.html` в корне репозитория — исходный вьюер (карта и список) одним
файлом. Разметка `Atlas.dc.html` и рантайм `support.js` взяты без изменений,
поэтому интерфейс, карта, погружение по доменам, боковая панель и список — те
же самые. Изменён только способ доставки зависимостей:

* React и ReactDOM 18.3.1 (те же UMD-сборки: SHA-384 сверены с константами
  `REACT_SRI` и `REACT_DOM_SRI` в `support.js`) встроены в `<head>`. Функция
  `loadReactUmd()` в рантайме сама пропускает обращение к CDN, если
  `window.React` уже определён, — код рантайма править не пришлось.
* Шрифты IBM Plex Sans, IBM Plex Mono и Spectral встроены как woff2 в base64
  (подмножества cyrillic и latin). Без этого браузер без интернета съезжал бы
  на системный шрифт, то есть на другую типографику.
* Данные встроены в `<head>` вместо `<script src="data.js">`.
* Холостой запрос соседнего компонента (`./Atlas.dc.html`, которого рядом нет)
  погашен штатным хуком `window.__resources`.
* Число тем в плейсхолдере поиска и на заставке было вписано вручную (30 343)
  и к данным не привязано — теперь считается по массиву.

Проверено в браузере с полностью отрезанной сетью: ноль внешних запросов,
ноль ошибок в консоли, карта и список работают.

## data.js

`data.js` — тот же массив `window.__TAXONOMY__` в прежнем формате, если вы
хотите подставить данные в свою копию `Atlas.dc.html` + `support.js`:

```js
window.__TAXONOMY__ = [
  { id, title, subtitle, icon, color, level, entries:[{ id, title, description }] },
  …
];
```

Разделы раскладываются по восьми доменам через поле `level` — оно сохранено,
поэтому все новые разделы попадают на карту без правок вьюера.
