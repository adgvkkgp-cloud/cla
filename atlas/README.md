# Атлас человека — таксономия

Интерактивная карта знаний о человеке: от хромосом и гормонов до психики, общества,
культуры и тончайших черт личности.

**615 разделов · 49 913 позиций · 8 доменов**

## Как посмотреть

`Atlas.dc.html` — самодостаточный вьюер. Семь режимов просмотра:

| Режим | Что показывает |
| --- | --- |
| Карта | Граф-дерево с погружением по уровням |
| Список | Разделы с раскрытием, слева — рельс доменов и дисциплин |
| Таблица | Плоский перечень тем с сортировкой |
| Плитка | Карточки доменов со сводкой по дисциплинам |
| Колонки | Домен → дисциплина → раздел → тема в четыре столбца |
| Связи | Темы, соединённые общими словами и тегами |
| ♂♀ | Только темы с различением мужского и женского |

Поверх любого режима работают поиск и полоса фильтров — по домену,
дисциплине, разделу, ярлыку, наличию механизма и граней пола.

### Ярлыки

а не руками по позициям. Ярлык у позиции один, порядок применения:
перебор → правило раздела → правило заголовка.

Помечено 21 468 позиций из 49 913 (43 %). Непомеченная позиция — это
норма: ярлык ставится там, где сужает выдачу осмысленно.

Главное, ради чего это сделано, — ярлык `сочетание`. Больше трети корпуса
это разделы вида «Любовь к: лесу», «Равнодушие: толпа» — один список
объектов, умноженный на семь отношений. Теперь их можно убрать
из выдачи одним щелчком, не удаляя из данных.

### Переписывание коротких описаний

Медиана длины описания по корпусу — 46 знаков, но в старых разделах
она падала до 8–20. Такие описания не сообщали ничего сверх заголовка:
«Фактор O», «Фасета C», «Младенчество», «Стадия знакомства». Позиция
при этом занимала место в выдаче и выглядела наполненной.

Новые описания лежат в `src/data/rewrites.ts` и заменяют прежние
по точному совпадению заголовка. Заголовки не трогаются: позиция
остаётся на своём месте, меняется только описание.

Сборку роняют две проверки: заголовок не найден и новое описание
не длиннее прежнего. Вторая существеннее — она не даёт внести
переписывание, не добавляющее содержания.

Повторы внутри раздела разводятся по содержанию, а не переписываются
одинаково: где две позиции называют одно и то же (например, «Принятие
жизни» и «Эго-интеграция» у Эриксона), первая описывает исход, вторая —
сам термин.

Переписано 325 позиций в тринадцати разделах; их медиана поднялась
с 8–19 знаков до 65–107.

Короткое описание само по себе поводом не является. `psy-phobias`
и `psy-phobias-2` держат самую низкую медиану в корпусе (14 и 16),
но «Акрофобия» → «Страх высоты» переводит непрозрачный термин,
а не пересказывает заголовок; в глоссариях черт и внешности короткая
строчная помета выдержана как единый приём на все позиции разом.
Оба случая оставлены как есть.

### Механизм

Поле `detail` — абзац о том, как устроено то, что названо в позиции:
из чего складывается, почему держится, чем разрывается. Это не второе
описание и не пример, а разбор устройства; там, где утверждение спорно
или держится на слабых данных, это сказано прямо в абзаце.

Абзацы лежат в `src/data/details.ts` таблицами вида
`{ "id-раздела": { "заголовок позиции": "абзац" } }` и дописываются
к уже существующим позициям при сборке, по точному совпадению заголовка.
Промах — заголовок, которого нет, — роняет сборку, поэтому таблица
не может разойтись с корпусом незаметно.

Написано 2 624 абзаца в 63 разделах (5,4 % корпуса). Поле заполняется
не сплошь, а по разделам: там, где за позицией стоит механизм, который
стоит объяснить. Один и тот же заголовок, встречающийся в нескольких
разделах, разбирается один раз — в том разделе, которому он принадлежит
по существу. То же правило действует внутри раздела: там, где одно
и то же понятие внесено под двумя названиями (`Tu quoque` и `Тю квокве`,
`Композиция` и `Ошибка композиции`, `Островковая доля` и `Островковая кора`),
механизм написан один раз, а у синонима поля нет.

### Грани пола

Поля `male` и `female` — короткая справка о том, чем различаются
мужчины и женщины по этой позиции. Правило заполнения жёсткое
и записано в `src/data/facets.ts`:

- различие называется вместе с величиной — «выше на 10–15 см»,
  «вдвое чаще», «разрыв рекордов около 10 %». Направление без
  величины почти ничего не сообщает;
- где различия нет, где оно мало́ по сравнению с разбросом внутри
  пола или где оно оспаривается, поле остаётся пустым. Пустое поле —
  честный ответ, а не пробел; вьюер ставит на этой стороне «—»;
- позиции о самой изменчивости и о совпадении диапазонов полей
  не получают вовсе: они говорят не о различии, а о том, как его
  читать.

Сборка роняется дважды: при промахе по заголовку и при попытке
внести позицию с двумя пустыми сторонами.

Заполнено 804 позиции в 55 разделах (1,66 % корпуса).

### Систематика

Определение строится как ближайший род + видовое отличие, и каждое
видовое отличие может делиться дальше. Раньше эта иерархия жила
только в заголовках — «Монархия как форма правления», «Основание
деления монархий», «Признаки федерации» — и в списке все позиции
стояли вровень. Теперь она записана явно: правила и таблицы лежат
в `src/data/tree.ts`, при сборке позиции получают поля

| Поле | Что значит |
| --- | --- |
| `up` | Родительская позиция |
| `upS` | Раздел родителя, если род описан в другом разделе |
| `rel` | `вид` — деление понятия, `часть` — расчленение целого, `основание` — позиция, описывающая само деление, `признаки` — перечень признаков другого понятия, `положение` — суждение о понятии: свойство, соотношение, оценка, возражение |
| `by` | Основание деления: признак, по которому виды различаются |
| `diff` | Видовое отличие, грамматически продолжающее род |
| `home` | Основное место понятия, если оно описано в другом разделе |

Вьюер собирает определение сам: «Абсолютная монархия — монархия,
в которой власть монарха не ограничена ни конституцией, ни
представительным органом». Отличие-оборот отделяется запятой,
отличие-обстоятельство присоединяется прямо: «Премия — стимулирующая
выплата за достигнутые результаты». Уточнение в скобках в имени рода
(«Сдерживание (стратегия)», «… (Фрикер)») в определение не переносится. На карте раздел раскрывается в корень
дерева, понятие — в свои деления (через позицию-основание или группу
«виды по …»); в списке позиции идут в порядке дерева с отступами
и строками-заголовками делений. В боковой панели — блок «Систематика»:
определение, род, основание деления, соседние виды и виды по каждому
делению; все названия кликабельны. Позиции-дубли в других разделах
получают кнопку «Основное место в дереве».

Таблицы пишутся строками: `[заголовок, узел]` ставит на место
существующую позицию, `[заголовок, описание, узел]` дописывает
недостающую ступень деления в раздел — там же, где ставит её на место.
Позиции, сознательно оставленные вне дерева, перечисляются в `free`.

Род может лежать в другом разделе: узел пишется как
`"x20-tgp::Норма права"`. Так понятие остаётся там, где оно подробно
описано, а деление собирается из разных разделов без копий:
«Преступление» живёт в уголовном праве и стоит видом «Правонарушения»
из теории права, «Буквальное толкование» — в разделе о толковании
и видом «Толкования права». Позиции разделов-классификаций («Нормы
по характеру предписания — управомочивающие, обязывающие,
запрещающие») становятся узлами-основаниями этих деревьев. В своём
разделе такая позиция — корень с пометкой рода и раздела, в разделе
рода — его вид; на карте ветви проходят через разделы, в панели
позиция из другого раздела помечена стрелкой ↗.

Сборка роняется, если родитель не найден, есть цикл (в том числе
через разделы), у вида нет основания или отличия, в делении меньше
двух видов или позиция систематизированного раздела осталась вне
дерева, не ведёт в чужое дерево и не объявлена свободной. Соразмерность
и исключаемость деления механически не проверяются — они держатся
на разборе.

Всего в деревьях 19 741 позиция из 461 раздела, из них 4 070 видов
с собранным определением и 325 оснований деления; 6 197 связей идут
через разделы, 2 814 дублей ведут в основное место. Глубина — до
тринадцати ступеней. Систематизированы весь правовой и
государственно-политический блок, нация, насилие, доктрины,
понятийный аппарат, пол и формы союза, прикладная и общая
социология (все разделы soc-*), социальная теория, экономика,
логика, методология, философия и её история, этика и мысленные
эксперименты, вся психология (разделы psy-*, x13, x33, x38, x39,
x43), половые различия, культурные формы (x12), прикладные знания
(x26, x34, x36, x37, x40, x41, x45–x49): медицина, биология,
педагогика, языкознание, литературо-, искусство- и религиоведение,

Частично размеченных разделов не осталось: каждая таблица в
`tree*.ts` отмечена как систематизированная целиком. Заголовки вида
«… как форма правления» приведены к имени понятия, множественное
число — к единственному, чтобы определение согласовывалось. Разделы
без систематики не тронуты: у их позиций полей нет, и вьюер
показывает их как раньше.

Открывается
по локальному HTTP (не по `file://` — браузер блокирует загрузку скриптов):

```bash
cd atlas
python3 -m http.server 8080
# и открыть http://127.0.0.1:8080/Atlas.dc.html
```

Вьюеру нужны `support.js` и `data.js` рядом (`icon.svg` и `manifest.webmanifest` —
по желанию, для установки на телефон).

### С телефона

Двойной щелчок по `Запустить.bat` (Windows) или `Запустить.command` (macOS)
в корне репозитория: поднимется сервер, откроется страница с QR-кодом, ссылка
на Атлас окажется в буфере обмена. Навести камеру телефона на QR — и всё.
Подробности и что делать, если телефон не открывает, — в корневом `README.md`.

Можно и по-старому: `python3 -m http.server 8080` и адрес вида
`http://<ip-компьютера>:8080/atlas/Atlas.dc.html` — или положить папку
на любой статический хостинг.

Что сделано под мобильный экран (ниже 820 px по ширине или ниже 520 px по высоте):

- шапка переносится в две строки, счётчики сжимаются до `615 · 49 913`,
  поле поиска занимает всю ширину и получает шрифт 16 px — иначе Safari
  сам увеличивает страницу при фокусе;
- боковая панель превращается в нижнюю шторку: появляется только при выборе
  узла, имеет полоску-ручку и крестик, не скроллит страницу под собой;
- кнопки карты уходят вправо вверх и вырастают до 42 px, легенда доменов
  становится прокручиваемой строкой внизу, подсказка меняет текст на тач;
- жесты: одно касание — раскрыть, двойное — погрузиться, щипок двумя
  пальцами — зум, перетаскивание — панорама; область попадания по узлу
  увеличена с 16 до 26 px;
- граф на узком экране считается по более плотным кольцам и с короткими
  подписями, иначе после вписывания текст нечитаем;
- ландшафт телефона разбирается отдельно: панель сужается до 300 px,
  шапка и кнопки ужимаются, легенда и подсказка убираются;
- есть манифест и иконка — страницу можно добавить на домашний экран,
  она откроется без адресной строки.

Настольная раскладка не изменилась ни на пиксель: все мобильные правила лежат
внутри медиазапросов, а логика ветвится по ширине окна и типу указателя.

### Формат

```ts
interface Section { id, title, subtitle, icon, color, level, entries: Entry[] }
interface Entry   { id, title, description, detail?, male?, female?, tag?,
                    up?, rel?, by?, diff?, home?, o? }   // систематика — см. выше
```

Поле `level` — не украшение: по нему вьюер раскладывает разделы по восьми доменам
и по подгруппам внутри них (`_domainOf` в `Atlas.dc.html`). Новый раздел с незнакомой
строкой `level` уедет в домен «Психика и личность» по умолчанию.

## Пересборка данных

```bash
cd atlas
npm install          # esbuild приходит вместе с vite
npm run build:data   # то же самое: node tools/build-data.cjs
```

Скрипт падает с ненулевым кодом, если найдёт разрыв в нумерации, пустое поле,
повтор `id` раздела или повтор заголовка внутри одного раздела.

## Правила пополнения

1. **Сначала ищем существующий раздел.** Новый раздел заводится, только если позиции
   действительно некуда положить.
2. Заголовок уникален внутри своего раздела. Одно и то же понятие может встречаться
   в разных разделах под уточняющим заголовком — например, «Ирония (фигура речи)»
   рядом с «Ирония» в разделе про юмор.
3. Описание — одно предложение, которое объясняет суть, а не пересказывает заголовок.
4. Новый раздел получает `level` из уже существующего набора строк, иначе он выпадет
   из своего домена.
