# Таксономии

| Папка | Что это | Открыть на компьютере |
| --- | --- | --- |
| `atlas/` | Атлас человека — 615 разделов, 48 575 позиций | через сервер (ниже) |
| `face/` | Таксономия лица | двойной щелчок по `TAXONOMY_FACE.html` |
| `telo/` | Таксономия телосложения | двойной щелчок по `TAXONOMY_TELO.html` |
| `TAXONOMY_MEGA.html` | Мега-таксономия еды | двойной щелчок |

Атласу без сервера нельзя: он при запуске запрашивает собственную страницу
(`fetch(location.href)`), а с `file://` браузер такой запрос не выполняет.
Трём остальным сервер не нужен — всё внутри одного файла.

## На телефоне

1. Двойной щелчок по **`Запустить.bat`** (Windows) или **`Запустить.command`** (macOS).
2. Откроется страница с QR-кодом. Навести на него камеру телефона.

Всё. Телефон должен быть в той же сети Wi-Fi, что и компьютер.

Что делает запуск:

- поднимает сервер на всю локальную сеть — порт 8080, а если он занят, то 8000;
- находит адрес компьютера в сети — тот, по которому достучится телефон;
- кладёт ссылку на Атлас в буфер обмена — можно отправить её себе в мессенджер;
- открывает страницу с QR-кодами всех четырёх таксономий и кнопкой «Копировать»;
- печатает тот же QR-код прямо в окне — на случай, если браузер не открылся;
- сжимает файлы при отдаче: `data.js` Атласа уходит на телефон 1,7 МБ вместо 9,4;
- запрещает телефону кешировать старые файлы — после пересборки не надо чистить кеш.

Остановить — кнопка «Остановить сервер» на странице или просто закрыть окно.
Повторный запуск, пока сервер работает, второй сервер не поднимает, а открывает
страницу уже работающего.

Нужен только Python 3.7+ — никаких пакетов. QR-код считается в самом `serve.py`.
Без двойного щелчка то же самое: `python3 serve.py`.

### Если телефон не открывает ссылку

- **Windows при первом запуске спросит разрешение для Python** в брандмауэре.
  Разрешить — иначе телефон не достучится.
- Сеть в Windows должна быть **«Частной»**: в «Общедоступной» входящие подключения
  закрыты. Параметры → Сеть и Интернет → свойства текущей сети.
- Гостевая сеть роутера обычно изолирует устройства друг от друга — подключите оба
  к основной.
- С включённым VPN адрес может оказаться не тем. На странице есть запасные адреса.
- macOS при первом запуске `.command` может сказать «неизвестный разработчик» —
  правый щелчок → «Открыть».

### Ограничение

Ссылка работает, пока компьютер включён и сервер запущен. Адрес компьютера в сети
может смениться после перезагрузки роутера — тогда QR-код будет новый, и старая
закладка на телефоне перестанет открываться.

Атласу на телефоне нужен интернет: React он подгружает с unpkg.com. Остальным
трём — нет.
